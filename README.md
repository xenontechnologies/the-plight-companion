# The Plight Companion

Build a mobile-responsive AI mental health chatbot platform called The Plight. Create a complete front-end with three core sections:

Landing Page: Clear value proposition for users seeking mental health support. Prominent CTA button “Chat Now” that launches the AI chatbot. Include WhatsApp integration for direct messaging. Highlight features: confidential support, AI-guided coping strategies, and 24/7 availability. Include testimonials or user reassurance.

Chatbot Page: Interactive AI chat interface with conversation history, typing indicators, and emotion-aware responses. Include option to escalate to human support. Ensure accessibility and mobile responsiveness.

About Us Page: Overview of the organization, mission, values, and commitment to mental health. Include team introduction, privacy and security assurances, and contact information.

Ensure modular design to support future scaling, analytics tracking, and seamless integration with back-end services. Optimize UX for trust, simplicity, and engagement.
